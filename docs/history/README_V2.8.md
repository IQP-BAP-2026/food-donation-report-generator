# Generador de Reportes BAP V2.8

Refinamiento de fidelidad para reportes monetarios.

- Los fondos Canva siguen siendo la fuente visual de verdad y solo se usan en reportes monetarios.
- Botones principales de Inicio vuelven a rectángulos grandes con bordes redondeados.
- Tipografía monetaria adaptativa: texto corto crece y texto largo disminuye dentro de zonas seguras.
- Zonas seguras por diseño protegen los elementos decorativos superiores.
- Indicadores centrados verticalmente dentro de sus cajas Canva.
- Cierre corregido: 9 fotos obligatorias en una cuadrícula 3x3 contenida dentro del A4.
- Fotos usan object-fit: cover y no expanden sus filas.
- La plantilla monetaria mantiene límites de texto, fotos e indicadores.
- El flujo de alimentos y la plantilla de Cam no fueron rediseñados.

# Generador de Reportes BAP v2.7

Cambios principales de v2.7:
- Inicio rediseñado sin barra lateral.
- Dos botones circulares grandes, centrados horizontal y verticalmente, para Alimentos y Monetario.
- Pie de página rosado con Manual, Reportes guardados, Plantillas monetarias, Configuración y Salir.
- El flujo monetario ahora tiene una pestaña dedicada **3. Cierre** para editar el mensaje final y seleccionar/reemplazar exactamente 9 fotos.
- La pestaña Diseño pasa a ser **4. Diseño**.
- Corregida la alineación de indicadores en las páginas de Resultados numéricos de 1, 2, 3 y 4 indicadores para que el contenido quede dentro de los recuadros exactos del fondo Canva.
- Se mantienen los fondos Canva originales sin rediseñarlos.
- Se mantienen las validaciones de texto, fotografías e indicadores y el bloqueo de contenido que no cabe.
- El diseño Canva sigue siendo exclusivo de reportes monetarios; alimentos conserva el generador de Cam.

## Compilación
Ejecute `BUILD_EXE.bat` en Windows. El resultado es una distribución one-folder.
